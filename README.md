# Menu Especial de Natal — Toronto Cuisine Gourmet

Site estático HTML com o cardápio especial de Natal (7ª edição) formatado em proporção visual A4.

## 📁 Estrutura de Arquivos

- `index.html`: Página principal com navegação vertical responsiva e suporte a impressão A4.
- `assets/`: Imagens em formato WebP otimizado das 8 páginas do menu e favicon.
- `vercel.json`: Cabeçalhos e configuração de cache para deploy na Vercel.

## 🚀 Como Publicar na Vercel

1. Importe este repositório na sua conta da [Vercel](https://vercel.com).
2. Deixe o **Framework Preset** como **Other**.
3. **Build Command**: desativado (em branco).
4. **Output Directory**: raiz (`./`).
5. Clique em **Deploy**.
